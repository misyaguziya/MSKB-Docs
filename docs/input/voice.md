# 音声入力

1. キーボードのマイクのキーを押して、話します。
2. もう一度押して止めます。
3. 聞き取った文が入力欄に入るので、確かめて直し、↵ で送ります。

聞き取っている間は、手首のボタンに「マイク」と出ます。

## 初めて使うとき

聞き取りの準備のため、データを取得します（インターネットが必要です）。
準備中は、マイクのキーと手首のボタンに「マイク nn%」と進み具合が出ます。

## マイクを選ぶ

使うマイクは、設定の「入力と音」→「マイク」で選びます（PC の設定画面と VR の歯車のどちらでも選べます）。
PC の設定画面では「テスト」を押すと入力レベルを確かめられます。確かめたら「止める」を押してください。

:::tip うまく聞き取れないとき
- 「マイクを開けませんでした」と出るときは、Windows の設定でマイクの使用が許可されているか確かめます。
- 入力レベルが動かないときは、ほかのマイクを選びます。VR 機器のマイクを使うときは、その機器のマイクを選びます。
:::
