# FAQ

## キーボードが出ない

- SteamVR と MSKB が起動しているか確かめます。PC の設定画面の下に「SteamVR 連携中」と出ていれば連携しています。
- 手首のボタンを押すか、長押しして目の前に呼び戻します。
- 手首のボタンも見えないときは、PC の設定画面の「VR操作」→「目の前に戻す」を押します。

## 手首のボタンが見えない

- 「手首を見たときだけボタンを出す」がオンのときは、手首をこちらへ向けると出ます。
- ボタンを付ける手が反対になっていないか、VR の歯車の「VR操作」で確かめます。ずれているときは「ボタンを手首に戻す」を押します。
- 「手首のボタンを出す」をオフにしているときは、選んだショートカットで開きます。

## キーが押せない・指しても反応しない

- **初回の準備中**：手首のボタンに「辞書 nn%」と出ている間は、日本語・中国語のキーは押せません。終わるまで待ちます（[初回の準備](./start/install.md#4-初回の準備を待つ)）。
- **ポインターがずれる**：[ポインタの角度](./customize.md#ポインタの角度) を変えます。
- **トリガーが効かない**：PC の設定画面の「VR操作」→「入力状態の確認」を押し、表示に従います。ボタンの割り当てを変えたときは、「MSKBのボタン割り当て」から SteamVR の画面を開き、MSKB の既定の割り当てを選んで適用すると元に戻ります。
- SteamVR のメニュー（ダッシュボード）を開いている間は、キーボードは操作できません。

## 変換されない・英字のまま入る

- 左上の「半/全」で英数の入力になっていないか確かめます。もう一度押すと、かなに戻ります。
- 🌐 キーで「日本語」が選ばれているか確かめます。

## チャットボックスに送れない

- VRChat のアクションメニューで「OSC」が有効か確かめます（[インストールと起動](./start/install.md#5-vrchat-の-osc-をオンにする)）。
- 入力欄右端の送る先が、吹き出しの印になっているか確かめます。
- VRChat の入力欄が開いていると、チャットボックスではなく入力欄に入ります。入力欄を閉じてから送ります。
- 手首のボタンに「OSC エラー」、設定画面の下に「VRChat エラー」と出るときは、設定画面の「OSC」の接続先を確かめます。ふだんは `127.0.0.1`・`9000` のままで使えます。

## VRChat の入力欄に文字が入らない

- VRChat を管理者として実行していると、文字を入れられません。VRChat を通常どおり起動してください。
- 「VRChat が見つからないので、コピーだけしました」と出たときは、VRChat が起動しているか確かめてから、もう一度 ↵ を押します。

## 全消去できない

入力欄の右端の「×」は、続けて 2 回押すと消えます。1 回目は色が変わるだけです。

## キーの音が HMD から聞こえない

キーの音は、Windows の既定の再生デバイスから鳴ります。
SteamVR の設定の「オーディオ」で、再生デバイスを HMD に切り替える設定を確かめます。

## 音声入力で文字にならない

- 設定の「入力と音」でマイクを選び、「テスト」を押して入力レベルが動くか確かめます。確かめたら「止める」を押します。
- 「マイクを開けませんでした」と出るときは、Windows の設定でマイクの使用が許可されているか確かめます。

## 設定画面を閉じたら MSKB が終了した

初期設定では、設定画面の「×」で MSKB が終了します。「一般」→「閉じるとシステムトレイに入る」をオンにすると、閉じてもトレイで動き続けます。

## Quest 単体で使える？

使えません。Windows PC と SteamVR が必要です。

## 解決しないとき

[GitHub の Issues](https://github.com/misyaguziya/MSKB-Docs/issues/new/choose) から「不具合の報告」を選んで、次の内容をお知らせください。

- MSKB のバージョン（PC の設定画面の左下）
- 使っている VR 機器
- 行った操作と、困っている内容
- エラーのログ（設定画面の「困ったとき」→「エラーのログ」の「コピー」）

GitHub のアカウントがない場合は、[BOOTH](https://misyaguziya.booth.pm/items/9093442) のメッセージでも受け付けています。

:::caution
Issues は公開の場所です。エラーのログを貼るときは、ユーザー名の部分を消してください。
:::
