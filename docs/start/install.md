# インストールと起動

## 1. ダウンロードする

[BOOTH の MSKB の商品ページ](https://misyaguziya.booth.pm/items/9093442) から、zip ファイルをダウンロードします。
ご利用前に、zip に入っている `LICENSE.txt`（利用規約）をご確認ください。

## 2. インストールする

1. zip を展開し、中のインストーラーを開きます。
2. 案内に沿ってインストールします。

:::tip 「Windows によって PC が保護されました」と表示されたとき
「詳細情報」を押してから「実行」を押します。
:::

:::caution
Windows 11 の「スマート アプリ コントロール」がオンの PC では、起動できない場合があります。
:::

## 3. 起動する

1. SteamVR と VRChat を起動します。
2. MSKB を起動します。

PC に設定画面が開き、VR の中では左手首にボタンが出ます。

:::tip
設定画面の「一般」→「SteamVR と同時に起動」をオンにすると、次からは SteamVR を起動するだけで MSKB も起動します。
:::

## 4. 初回の準備を待つ

初めて日本語・中国語を打つときは、変換に使う辞書を取得して準備します（インターネットが必要です）。
準備中は、手首のボタンに「辞書 nn%」と出て、キーボードの候補の段に進み具合の線が出ます。終わるまでキーは押せません。

- 準備には、ダウンロードのあと約 15 秒かかります。2 回目からはすぐに使えます。
- 準備中でも、🌐 キーで English か 한국어 に切り替えれば打てます。
- 失敗したときは、候補の段の「もう一度試す」を押します。

## 5. VRChat の OSC をオンにする

MSKB は、VRChat の OSC を使ってチャットボックスへ送ります。

1. VRChat のアクションメニューを開きます。
2. 「OSC」を開き、「Enabled（有効）」をオンにします。

一度オンにすれば、次からは不要です。

:::caution
VRChat を管理者として実行していると、VRChat の入力欄に文字を入れられません。VRChat は通常どおり起動してください。
:::

## 終了するとき

Windows のタスクトレイにある MSKB のアイコンを右クリックし、「終了」を選びます。
アイコンが見当たらないときは、タスクバー右端の「^」を押すと出てきます。

設定画面の「×」は、初期設定では MSKB を終了します。閉じても使い続けたいときは、「一般」→「閉じるとシステムトレイに入る」をオンにします。
