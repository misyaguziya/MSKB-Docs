## What it can do

| | |
|---|---|
| Typing | Japanese (romaji and flick), English, 한국어, 简体中文, 繁體中文 (Pinyin, Zhuyin, Cangjie, Quick), voice input |
| Symbols | Symbols, brackets, shapes, arrows and math, emoji, kaomoji, phrases |
| Editing | Moving the cursor, selecting, copy and paste, undo, recalling sent messages |
| Sending | Send to VRChat's chatbox, or enter text into VRChat's text fields |
| Looks and sound | Colors, opacity, a picture behind the keys, a sound for each key, vibration |

The settings window and the keyboard can be shown in 日本語, English, 한국어, 简体中文 or 繁體中文.

## Requirements

- A Windows PC
- SteamVR and a VR headset that works with SteamVR
- VRChat for PC

MSKB does not work on a standalone headset such as Quest by itself.
You need an internet connection for the first-time setup and the first time you use voice input.
