# Voice input

1. Press the microphone key on the keyboard and speak.
2. Press it again to stop.
3. What was heard goes into the text field. Check and fix it, then send with ↵.

While listening, the wrist button shows "Microphone".

## The first time

MSKB downloads the data for listening (you need an internet connection).
While it prepares, the microphone key and the wrist button show the progress as "Microphone nn%".

## Choosing a microphone

Choose the microphone under "Input & sound" → "Microphone" in the settings (either the PC settings window or the VR gear).
In the PC settings window, press "Test" to check the input level. Press "Stop" when you are done.

:::tip If it doesn't hear you
- If you see "Could not open the microphone", check that microphone access is allowed in Windows settings.
- If the input level doesn't move, choose another microphone. To use your headset's microphone, choose that device.
:::
